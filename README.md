An early-momentum rider for the pump.fun paper-trading replay. It buys only curves whose price is already up ~25% from birth with buyers dominating the recent tape, sizes up on the strongest runs, and exits by rule: half off at 2x, half of the rest at 4x, a trailing stop once a winner is armed, a hard stop under cost, and a stale exit that frees the slot. One buy per coin, at most five open at once, plus a small guardrail probe so the run clears the twenty-coin round-trip bar. Fully deterministic — every decision comes from the event stream alone.

## Run it

```sh
node main.ts
```
